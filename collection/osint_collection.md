# OSINT Collection

## Purpose

This document describes a structured approach to collecting publicly available information for Cyber Threat Intelligence (CTI) analysis.

## Collection Areas

- Domain information
- IP address information
- DNS records
- Certificate information
- Public infrastructure
- Threat-actor information
- Malware indicators
- Publicly available technical reports

## Collection Process

1. Define the intelligence requirement.
2. Identify relevant information sources.
3. Collect publicly available information.
4. Record and normalize collected indicators.
5. Validate information using multiple sources.
6. Prepare the information for analysis.

## Safety

Only publicly available, simulated or authorized information should be collected for this portfolio.

No classified, private, credential, or operationally sensitive information should be included.
