# Threat Assessment

## Purpose

Threat assessment combines collected indicators and analytical findings to develop a structured understanding of potential cyber threats.

## Assessment Framework

| Element | Description |
|---|---|
| Indicator | Technical indicator being assessed |
| Type | IP, domain, URL, hash or other indicator |
| Observation | Relevant observed activity |
| Context | Intelligence surrounding the indicator |
| Confidence | Confidence in the assessment |
| Action | Suggested investigative follow-up |

## Assessment Principles

- Use evidence-based analysis.
- Distinguish facts from assessments.
- Record confidence levels.
- Correlate information from multiple sources.
- Document analytical assumptions.
